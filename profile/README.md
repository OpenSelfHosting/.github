# OpenSelfHosting

**OpenSelfHosting** is a software company focused on building modern projects designed for **self-hosting**.

We build software that allows individuals, developers, teams, and organizations to run their own applications on infrastructure they control.

Our projects focus on:

* **Self-hosting**
* **Privacy**
* **Security**
* **Data ownership**
* **Infrastructure independence**

We believe software should give users more control over how it is deployed, where it runs, and how their data is managed.

> **Build it. Host it. Own it.**
